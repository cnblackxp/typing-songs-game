# Lyric Volley

A rhythm typing trainer. Lyrics fall in time with a song. Type the falling word and press **Enter** (or **Space**) to fire it at the word and blow it apart. Hit it as it crosses the beat line for an on-beat bonus.

## Files

- `game.html`: the game, written as an Artifact page body (no `<html>/<head>` shell). This is what gets published to claude.ai.
- `index.html`: standalone build with a full document shell, served by GitHub Pages at https://cnblackxp.github.io/typing-songs-game/ (add `?v=VIDEO_ID` to open a song directly). Generated by `node build.mjs`; don't edit it by hand.

## Song sources

| Source | Standalone `index.html` (served over http/https) | claude.ai artifact |
| --- | --- | --- |
| YouTube link | Plays the video via the YouTube IFrame API and fetches synced lyrics from [LRCLIB](https://lrclib.net) using the video title (looked up through noembed.com) | The viewer blocks YouTube embeds and outside requests. The game switches to **tap sync**: open the video in another tab, press Start, then press play there at zero. Paste the transcript yourself. |
| Audio file | Decodes the file locally and searches LRCLIB by file name | Plays the file; paste the lyrics |
| Demo (Neon Rain) | Original song synthesised live with Web Audio, original lyrics | Same |

The lyrics box accepts LRC, SRT/VTT, a transcript copied from YouTube (… → Show transcript), or plain lines with no times. Plain lines fall at a steady pace.

## How a song plays

Each lyric line falls as a row of words and reaches the stave line as the singer finishes it. Type the words in any order; Space or Enter fires the typed word. Firing a word while it's being sung scores an on-beat bonus.

On **Easy** and **Normal** the song waits for you: if a word gets too low, the music (YouTube video, audio file or demo) pauses until you clear it, so every line can be typed at your own pace. **Hard** and **Expert** never wait: words that reach the baseline damage it, and a broken baseline ends the run.

Options on the menu:

- **Words**: *All lyrics* (default) or *Key words*, which drops only some words at the difficulty's pace and shows the rest of the line as faint text.
- **Song speed**: 100%, 75% or 50% for YouTube and the demo. Everything slows down together, so the timing still lines up.

## Difficulty

| | Fall time | The song waits | Matching | Fail |
| --- | --- | --- | --- | --- |
| Easy (default) | 8 s | yes | capitals and punctuation ignored | no |
| Normal | 6 s | yes | capitals and punctuation ignored | no |
| Hard | 4.5 s | no | apostrophes count | yes |
| Expert | 3.2 s | no | exact capitals, apostrophes, hyphens | yes |

Tap sync (when a video can't be embedded) can't pause the other tab, so the song never waits there.

## Controls

- `Enter` / `Space` (or the Fire button): fire the typed word
- `Esc`: pause
- `[` / `]`: shift lyric timing by 0.1 s mid-song
- On phones, tap the playfield to bring the keyboard back. The layout follows the visual viewport, so the type bar stays above the keyboard.

## Build

```sh
node build.mjs   # regenerates index.html from game.html
```
